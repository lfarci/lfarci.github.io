C# Quest Tracker

A browser-local companion for tracking challenges and XP while working through The C# Player's Guide, fifth edition.

Problem
Keep learning progress visible and transfer it between devices without an account.
My role
Personal project development: interface, progress tracking, and backup workflow.
Design
Static application with local browser storage and explicit CSV import/export. No backend or database.
  • HTML
  • CSS
  • JavaScript
  • GitHub Pages

Limits: No cloud sync; clearing browser storage can erase progress. An unofficial companion, not endorsed by the book's author.

Agent Portability Lab

A reproducible investigation into distributing agent profiles across GitHub Copilot, Codex, and OpenCode with Microsoft APM.

Problem
Understand which parts of an agent setup carry between coding tools, and where native configuration is still needed.
My role
Experiment design, fixtures, compatibility checks, and documented observations.
Findings
Basic reviewer instructions transferred; tool-restriction translation exposed compatibility gaps.
  • Microsoft APM
  • Python
  • C# fixture
  • Coding agents

Limits: Narrow tests of APM 0.34.0 in October 2026. Runtime security enforcement was not tested; generated configuration is not proof of enforcement.
